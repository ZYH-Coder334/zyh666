# 涉密信息系统集成资质甲级（总体集成）申请材料编制与自检

## 一、任务背景

华信安通科技有限公司（以下简称"公司"）拟向国家保密行政管理部门申请**涉密信息系统集成资质甲级（总体集成）**。公司已按要求准备了一套申请材料，现委托你作为第三方合规审查顾问，对申请材料开展全面审查，编制审查工作底稿，并对公司管理层提出的申报要求逐项作出合规性判断。

**审核基准日：2025年9月1日**
**申报日期：2025年8月20日**

审查工作要求：结论必须有据可依（引用具体规则条款）、数据必须逐条核验（不得凭经验估算）、分类必须完整（符合 / 合规保留 / 不符合三类齐全）。

## 六、交付物要求（8包，与输入附件一一对应）

### 01差距分析报告.rar
工作表：`差距分析结论`
字段：序号、问题描述、法规依据、审查结论（符合/不符合/合规保留）、处理建议
要求：逐项对照16项资质条件，给出量化数据支撑（人数、金额、比例、年限），不得只写"符合/不符合"而无数据。

### 02社保核验答案.rar
工作表：`社保核验答案`
字段：序号、姓名、部门、岗位、社保起缴日期、缴费状态、审查结论、处理建议
要求：1000人逐人判定。判定口径为"缴费状态正常"且"社保起缴日期距基准日满12个月"，两者须同时满足。不符合项须写明具体原因。

### 03高级职称审查答案.rar
工作表：`高级职称审查答案`
字段：序号、姓名、职称名称、职称专业、专业归属（计算机类/非计算机类）、审查结论、处理建议
要求：80人逐人判定。须同时校验四项：①专业是否属计算机技术与软件相关专业（对照专业目录08/09编码）；②证书编号格式（Z开头，末位1=正高、2=副高）；③发证机关权限（正高须省部级机关）；④证书状态是否有效。任一不满足即不计入。

### 04涉密人员审查答案.rar
工作表：`涉密人员审查答案`
字段：序号、姓名、花名册序号、部门、涉密等级、问题类型、审查结论（符合/合规保留/不符合）、处理建议
要求：500人逐人判定，三类结论必须齐全：
- **不符合**：国籍非中国籍、配偶为外籍、未进行保密审查、审查已过期、未完成培训、培训已过期；
- **合规保留**：涉密等级为"一般"且属非涉密岗位、其他条件均合规，按非涉密岗位管理；
- 其余为**符合**。
问题类型须写明具体问题，不得笼统写"不符合"。

### 05集成收入核算答案.rar
工作表：`集成收入核算答案`
字段：序号、项目编号、项目名称、合同类型、合同额、是否计入、判定理由
要求：400个项目逐项判定。**7重条件须全部满足才可计入**：
1. 合同类型为"系统集成"；
2. 验收日期在2022-09-01至2025-08-31窗口内；
3. 甲方非关联方（须识别关联方名单中的"曾用名/别名"）；
4. 发票已开具且为全额（部分开票不计入）；
5. 涉密项目须有保密批文，非密项目须有非密认定；
6. 项目已归档；
7. 合同额以验收口径计入。
判定理由须写明被剔除的具体原因。另需统计千万元级（≥1000万元）项目个数。

### 06场所与制度审查答案.rar
工作表：`场所审查答案`、`设备权属审查答案`、`保密制度审查答案`

- 场所审查：序号、场所编号、用途、净面积、租期、问题类型、审查结论、处理建议
  - 净面积 = 建筑面积 − 公摊面积，须≥100㎡；
  - 租期须≥3年且租期终止日晚于基准日；
  - 须与非涉密场所物理隔离；
  - 设备密级不得超过场所密级；
  - 涉密档案室须"三铁"齐全（铁门、铁窗、铁柜）；
  - 综合办公区等非涉密场所列为"合规保留"。
- 设备权属审查：场所编号、场所性质、设备总数、自有权、租赁数、自有比例、审查结论、处理建议
  - 涉密场所自有比例须≥80%；非涉密场所不适用，列"合规保留"。
- 保密制度审查：序号、制度名称、建立情况、审查结论、处理建议
  - 40项制度逐项判定，缺失（无文件编号/发布日期）列"不符合"。

### 07错误要求驳回.rar
工作表：`错误要求驳回`
字段：序号、错误要求、违反依据、驳回意见
要求：对管理层18项要求逐项驳回，须引用具体的规则条款（如《收入确认规则》第3项），不得仅作原则性表态。

### 08勾稽与一致性自检.rar
工作表：`数据一致性核验`、`勾稽自检`

- 数据一致性核验：28项跨表核验，字段为序号、核验项、核验结果、审查结论、处理建议；
- 勾稽自检：23项汇总勾稽，字段为序号、勾稽项、验证数据、一致性。
要求：所有分类汇总必须满足"总数 = 符合 + 合规保留 + 不符合"，任一项不闭合即判定不一致。

## 七、审查要点提示

1. **三分类完整**：所有审查结论必须区分"符合 / 合规保留 / 不符合"，不得只做两类划分。合规保留是指事项本身不构成违规但也不计入符合条件（如非涉密岗位的涉密人员、非计算机类专业职称、非涉密场所）。
2. **边界日期处理**：审查日期恰好等于三年前、培训日期恰好等于一年前、验收日期恰好等于窗口首末日，均按"仍在有效期内/计入"处理。
3. **关联方识别**：关联方名单设有"曾用名/别名"列，项目清单中可能出现别名形式的甲方，须交叉比对识别。
4. **多条件叠加**：集成收入、高级职称、涉密场所均存在"表面合规、细节不合规"的情形，须逐条核对全部子条件。
5. **跨表勾稽**：人数、项目数、发票数、设备数、场所数、制度数在各表之间须完全闭合，任何"取数未用"或"汇总不闭合"均会失分。
6. **数据真实性**：申报员工总数与花名册实际人数、申报口径与管理层要求，均可能存在不一致，须以原始记录为准。

## 八、输出格式

按 8 个交付包分别提交，每个交付包内为对应工作表的 xlsx 文件。所有结论列使用"符合 / 合规保留 / 不符合"三值，处理建议列须给出可执行的整改动作。
