# 巷子里·小馆 — 扫码点单 SaaS 原型

面向小微餐饮的轻量门店系统：顾客扫码点单、后厨实时接单出餐、店长查看经营数据，三端通过本机浏览器实时联动，无需后端与数据库。

## 本地运行

```bash
cd /workspace
python3 -m http.server 5178
```

然后打开 http://localhost:5178

| 页面 | 地址 | 角色 |
| --- | --- | --- |
| 扫码点单 | `/index.html?table=08` | 顾客（支持任意桌号参数） |
| 后厨看板 | `/kitchen.html` | 后厨 |
| 店长看板 | `/admin.html` | 店长 / 收银 |

建议把点单页与后厨看板开在两个标签页，下单后能直观看到厨房端弹出新订单、顾客端进度条自动推进。

## 已实现

- 12 道菜、5 个分类，加购 / 减购 / 合计实时计算
- 桌号选择、备注、订单号生成（A001 递增）
- 订单状态机：待接单 → 制作中 → 已出餐 → 已结账
- 顾客端订单进度自动同步，后厨端超时订单高亮提醒
- 店长端：营业额、订单数、客单价、销量、时段柱状图、热销 Top 5、订单结账
- 数据存于 `localStorage`，跨标签页通过 `BroadcastChannel` 实时同步

## 目录

```
index.html        顾客点单
kitchen.html      后厨看板
admin.html        店长看板
assets/app.js     菜单、订单库、跨页同步、示例数据
assets/style.css  三端样式
```

首次打开会自动载入一份示例数据以便演示，可在店长看板点「清空数据」重置；加 `?empty=1` 打开也会跳过示例数据。

## 说明

这是可演示的产品原型：订单数据仅保存在本机浏览器，多个真实门店使用时需接入后端与账号体系。菜品/价格均为示例。
